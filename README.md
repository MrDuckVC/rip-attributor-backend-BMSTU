# Backend-сервис системы атрибуции анонимного текста

Бэкенд-компонент заявочной системы, разработанный в рамках курса «Разработка Интернет Приложений» (РИП, МГТУ им. Н.Э. Баумана, ИУ5).

## Предметная область

Система предназначена для лингвистического анализа и **атрибуции анонимного текста по частотности служебных слов**.
* **Услуги (Сущности каталога):** Корпусы текстов потенциальных авторов с предрассчитанной частотностью артиклей, предлогов и местоимений.
* **Заявки:** Расчет статистической значимости совпадений частотности служебных слов в анонимном тексте и текстах авторов-кандидатов.

## Технологии

* **Язык:** Go (Golang) 1.25.3+
* **Фреймворк:** Gin
* **Хранилище файлов:** MinIO
* **Контейнеризация:** Docker / Docker Compose

## Быстрый старт (Локальный запуск)

1. Клонируйте репозиторий:

   ```bash
   git clone [https://github.com/твои](https://github.com/твои)̆-аккаунт/attributor-backend.git
   cd attributor-backend
   ```

2. Настройка окружения:

   ```bash
   cp .env.example .env
    ```

3. Запустите инфраструктуру через Docker:

    ```bash
    docker-compose up -d
    ```

4. Запустите приложение:

    ```bash
    go run cmd/attributor/main.go
    ```

Сервер будет доступен по адресу: `http://localhost:8080`
